# StationOps

## Overview

StationOps is an enterprise-grade petrol station operations management platform designed to digitize and automate critical operational processes.

The initial module focuses on automating the cash drop process performed by Sales Assistants, replacing paper-based workflows with a secure, auditable and efficient digital system.

The long-term vision is to evolve StationOps into a complete station management platform supporting fuel sales, banking, inventory, shift management, reporting and operational analytics.

---

# Vision

To build a modern, secure and scalable platform that improves operational efficiency, accountability and transparency in petrol station operations.

---

# Current Module

Cash Drop Automation

Features include:

- Digital cash drop creation
- Automatic Drop ID generation
- QR code generation
- Thermal receipt printing
- Cash verification workflow
- Variance management
- Audit logging
- Role-based access control
- Session management
- Firebase Authentication
- Secure REST API
