# Cash Drop Automation System

## Project Overview

The Cash Drop Automation System is a web application designed to digitize and automate the cash dropping process at a petrol station.

## Goal

This project is being built as a learning project to master:

- Git
- GitHub
- NestJS
- Firebase
- Backend Development
- Software Engineering Best Practices

## Tech Stack

- NestJS
- Firebase Firestore
- HTML
- CSS
- JavaScript
- Git
- GitHub
